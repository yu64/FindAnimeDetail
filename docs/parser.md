# 構文仕様


## コマンド

```
/コマンド
```

```
$コマンド
```

```
@コマンド
```

## 引数構文

### パラメータ

```
#名称 値
```

### 準無名パラメータ

```
# 値
```

### 無名パラメータ

```
値
```

### リスト

```
#名称
値1
値2
```

リスト終端は、リスト構文ではなくなったとき

### 準無名リスト

```
#
値1
値2
```

リスト終端は、リスト構文ではなくなったとき

### 無名リスト

```
{直前がリストの場合、空行}
値1
値2
```

リスト終端は、リスト構文ではなくなったとき。

### フラットリスト

```
#名称 値1, 値2, ...
```

### 準無名フラットリスト

```
# 値1, 値2, ...
```

### 無名フラットリスト

```
値1, 値2, ...
```

### スイッチ

```
#名称
```

## エスケープ

### 文字列

```
"hoge, fuga"
```

```
#hoge, fuga#
```

### 記号

```
"hoge, ""fuga"{空白または改行}
```

```
#hoge, ##fuga#{空白または改行}
```


## 構成

```
{コマンド}[引数構文...]
[無名リストを除く、非無名引数構文][引数構文...]
...

```


## 例

--------------------------------------------------------------------------------

```
/hoge 53 23 13
```

- コマンド = hoge
- 無名パラメータ 1 = 53
- 無名パラメータ 2 = 23
- 無名パラメータ 3 = 13


--------------------------------------------------------------------------------

```
/hoge #a 10 #c 20 #b 30
```

- コマンド = hoge
- a = 10
- b = 30
- c = 20

--------------------------------------------------------------------------------

```
/hoge
a
b
c
```

- コマンド = hoge
- 無名リスト = ["a", "b", "c"]
--------------------------------------------------------------------------------

```
/hoge
fuga #a 12
```

- コマンド = hoge
- 無名リスト = ["fuga #a 12"]

--------------------------------------------------------------------------------


```
/hoge
fuga #a 12
fuga #a 12
```

- コマンド = hoge
- 無名リスト = ["fuga #a 12", "fuga #a 12"]


--------------------------------------------------------------------------------

```
/hoge
"a, b"
#a, b#
a, b
```

- コマンド = hoge
- 無名リスト = ["a, b", "a, b", "a, b"]


--------------------------------------------------------------------------------


```
/hoge #a 12 12
#b 12 12
#c 12 12 #d 12
hoge
fuga #a 12
#e 12
xxx
###yyy#
#f 12
```

- コマンド = hoge
- a = 12
- 無名パラメータ = 12
- b = 12
- 無名パラメータ = 12
- c = 12
- 無名パラメータ = 12
- d = 12
- 無名リスト = ["hoge", "fuga #a 12"]
- e = 12
- 無名リスト = ["xxx", "#yyy"]
- f = 12


--------------------------------------------------------------------------------


```
/hoge
fuga
#a 12
```

- コマンド = hoge
- 無名リスト = ["fuga"]
- a = 12


--------------------------------------------------------------------------------


```
/hoge #a 12, 13 ,14 , 15 16
```

- コマンド = hoge
- フラットリスト = ["12", "13", "14", "15"]
- 無名パラメータ = 16


--------------------------------------------------------------------------------


```
/hoge 
#a 12, 13 ,14 , 15
16
```

- コマンド = hoge
- フラットリスト = ["12", "13", "14", "15"]
- 無名リスト = ["16"]


--------------------------------------------------------------------------------

```
/hoge #a 12 # 12 12 #b 1,2 # 1,2 1,2 #x
#c 0 #d 12 # 12 12 #f 1,2 # 1,2 1,2 #y
#list
a
b
# 
a
b

a
b
```

- コマンド = hoge
- a = 12
- 準無名パラメータ = 12
- 無名パラメータ 12
- b = ["1", "2"]
- 準無名フラットリスト = ["1", "2"]
- 無名フラットリスト = ["1", "2"]
- x スイッチ
- c = 0
- d = 12
- 準無名パラメータ = 12
- 無名パラメータ 12
- f = ["1", "2"]
- 準無名フラットリスト = ["1", "2"]
- 無名フラットリスト = ["1", "2"]
- y スイッチ
- リスト = ["a", "b"]
- 準無名リスト = ["a", "b"]
- 無名リスト = ["a", "b"]


--------------------------------------------------------------------------------


```
/hoge #a #b 12 #c
hoge
fuga
```

- コマンド = hoge
- a スイッチ
- b = 12
- c スイッチ
- 無名リスト = ["hoge", "fuga"]


--------------------------------------------------------------------------------


```
/hoge
  hoge
fuga
```

- コマンド = hoge
- 無名リスト = ["hoge", "fuga"]


--------------------------------------------------------------------------------


```
/hoge
#hoge
fuga#
```

- コマンド = hoge
- hoge = ["fuga#"]


--------------------------------------------------------------------------------


```
/hoge #a 12 #b bb#
```

- コマンド = hoge
- a = 12
- 無名パラメータ = "b bb"


--------------------------------------------------------------------------------


```
/hoge #a 12# #b bb
```

- コマンド = hoge
- 無名パラメータ = "a 12"
- b = bb



--------------------------------------------------------------------------------


```
/hoge #a
#b
#c
```

- コマンド = hoge
- a スイッチ
- b スイッチ
- c スイッチ


--------------------------------------------------------------------------------


```
/hoge #a 12#bb
```

- パースエラー


--------------------------------------------------------------------------------


```
/hoge #
```

- パースエラー


--------------------------------------------------------------------------------


```
/hoge #
#
```

- パースエラー



--------------------------------------------------------------------------------


```
/hoge #name 山田
```

- コマンド = hoge
- name = "山田"

--------------------------------------------------------------------------------


```
/hoge #name "/hoge #name ""inner"""
```

- コマンド = hoge
- name = /hoge #name "inner"
